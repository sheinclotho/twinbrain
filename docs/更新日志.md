### 已知问题与限制
- ⚠️ WebSocketClientImproved使用HTTP而非真正的WebSocket
  - 原因：Unity原生不支持WebSocket，需要第三方插件
  - 影响：不支持服务器推送，需要轮询或请求-响应模式
  - 解决方案：未来可集成WebSocketSharp或NativeWebSocket
- ⚠️ OBJ模型运行时加载需要第三方插件
  - 推荐：TriLib, Runtime OBJ Importer
  - 替代方案：在Editor中预先导入OBJ作为资产

### 迁移指南

**从旧版WebSocketClient迁移到WebSocketClientImproved:**

```csharp
// 旧代码
wsClient.SendRequest("predict", parameters);

// 新代码（推荐，带回调）
wsClient.RequestPrediction(10, (response) => {
    if (response["success"].Value<bool>()) {
        // 处理成功
    } else {
        Debug.LogError(response["message"]);
    }
});

// 或继续使用SendRequest（向后兼容）
wsClient.SendRequest("predict", parameters, (response) => {
    // 处理响应
});
```

**从旧版安装方式迁移:**

```bash
# 旧方式：手动复制脚本
cp unity_examples/*.cs /path/to/Unity/Assets/Scripts/

# 新方式：使用自动安装工具
python unity_package_installer.py --unity-project /path/to/Unity
```
