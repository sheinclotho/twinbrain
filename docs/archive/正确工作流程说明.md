# TwinBrain 正确工作流程说明

## 概述

本文档说明 TwinBrain 系统的**正确使用方式**，特别是 FreeSurfer 与数据加载的关系。

## 🎯 核心理解

### FreeSurfer 的作用

**FreeSurfer 文件不是数据源，而是前端结构定义**

- FreeSurfer 文件只用于**一次性创建** Unity 前端的基础结构
- 类似于建筑的框架，定义了空间布局
- 创建后，可以加载各种不同的数据进行可视化

### 数据的作用

**数据是内容，可以随时更换**

- 数据文件独立于 FreeSurfer
- 可以是原始 fMRI 数据、缓存的图数据、或模型输出
- 通过 JSON 格式映射到脑区
- 用颜色和时间轴展示变化

## 🔄 完整工作流程

### 步骤 1: 创建 Unity 前端结构（一次性）

**使用 FreeSurfer 文件**：

```bash
# 方式 1: 命令行
python unity_automation.py --freesurfer \
  --lh-surface data/lh.pial \
  --rh-surface data/rh.pial \
  --lh-annot data/lh.Schaefer2018_200Parcels_7Networks_order.annot \
  --rh-annot data/rh.Schaefer2018_200Parcels_7Networks_order.annot \
  --export-surface \
  --output unity_frontend
```

```python
# 方式 2: Python API
from unity_integration import load_freesurfer_data, BrainOBJGenerator

# 加载 FreeSurfer
atlas_info, loader = load_freesurfer_data(
    lh_surface='data/lh.pial',
    rh_surface='data/rh.pial',
    lh_annot='data/lh.Schaefer2018_200Parcels_7Networks_order.annot',
    rh_annot='data/rh.Schaefer2018_200Parcels_7Networks_order.annot'
)

# 导出结构（不需要数据）
obj_gen = BrainOBJGenerator(atlas_info=atlas_info)
obj_gen.export_brain_model(
    output_path='unity_frontend/brain_structure.obj',
    activity_data=None  # 不需要活动数据
)

# 可选：导出表面网格
loader.export_surfaces_as_obj(
    output_dir='unity_frontend',
    combine_hemispheres=True
)
```

**输出**：
- `unity_frontend/brain_structure.obj` - 3D 模型
- `unity_frontend/brain_surface_bilateral.obj` - 表面网格
- 配置文件定义了 200 个脑区的位置和属性

**这一步只需要做一次！**

### 步骤 2: 准备数据文件夹

**组织您的数据**：

```
data/brain_data/
├── subject_01_fmri.nii.gz     # 原始 fMRI 数据
├── subject_01_preprocessed.pt  # 缓存的图数据
└── model_output.pt             # 模型预测输出
```

**支持的数据格式**：

1. **原始 fMRI 数据** (`.nii.gz`, `.nii`)
   ```python
   import nibabel as nib
   fmri_img = nib.load('subject_01_fmri.nii.gz')
   ```

2. **缓存的图数据** (`.pt`)
   ```python
   data = torch.load('subject_01_preprocessed.pt')
   fmri_data = data['fmri'].x_seq
   ```

3. **模型输出** (`.pt`)
   ```python
   predictions = torch.load('model_output.pt')
   fmri_data = predictions['fmri']
   ```

### 步骤 3: 加载数据并转换为 JSON

**自动化方式**：

```python
# 运行示例脚本
python example_correct_workflow.py
```

**手动方式**：

```python
from unity_integration import BrainStateExporter
import torch

# 加载数据（根据您的数据格式）
data = torch.load('data/brain_data/subject_01_preprocessed.pt')
brain_data = {'fmri': data['fmri'].x_seq}

# 创建导出器
exporter = BrainStateExporter(atlas_info=atlas_info)

# 导出为 JSON
exporter.export_sequence(
    brain_activity=brain_data,
    output_dir='output/brain_states',
    start=0,
    end=200,
    step=1
)
```

**输出**：
- `output/brain_states/brain_state_0000.json`
- `output/brain_states/brain_state_0001.json`
- ...
- `output/brain_states/sequence_index.json`

### 步骤 4: 在 Unity 中可视化

**Unity 端操作**：

1. **导入前端结构**：
   - 将 `brain_structure.obj` 导入 Unity 场景
   - 或使用 `brain_surface_bilateral.obj` 获得真实表面

2. **加载 JSON 数据**：
   ```csharp
   // Unity C# 代码
   BrainVisualization viz = GetComponent<BrainVisualization>();
   viz.LoadBrainState("output/brain_states/brain_state_0000.json");
   ```

3. **播放时间序列**：
   - 使用时间轴控件
   - 自动加载连续的 JSON 文件
   - 脑区颜色根据活动值变化

### 步骤 5: 交互式实时预测（可选）

**启动后端服务器**：

```bash
python unity_automation.py --mode server
```

或

```python
from unity_integration import BrainVisualizationServer

# 加载模型
model = torch.load('checkpoints/best_model.pt')

# 创建服务器
server = BrainVisualizationServer(
    model=model,
    exporter=exporter,
    port=8765
)

# 启动
server.start()  # Unity 连接到 ws://localhost:8765
```

**Unity 端交互**：

```csharp
// Unity C# 代码
WebSocketClient client = GetComponent<WebSocketClient>();
await client.Connect();

// 发送虚拟刺激
var stimulation = new {
    type = "stimulation",
    target_regions = new int[] {10, 15, 20},
    amplitude = 0.5,
    duration = 10
};

await client.SendMessage(JsonUtility.ToJson(stimulation));

// 接收预测结果（自动转换为 JSON）
client.OnMessageReceived += (json) => {
    BrainState state = JsonUtility.FromJson<BrainState>(json);
    viz.UpdateState(state);
};
```

## 🔑 关键概念

### 为什么要这样设计？

1. **分离关注点**：
   - FreeSurfer = 结构定义
   - 数据 = 内容
   - 清晰的职责分离

2. **灵活性**：
   - 一次创建前端，多次使用
   - 可以加载不同的数据集
   - 可以切换数据源

3. **效率**：
   - 不需要重复生成 OBJ 模型
   - 只更新数据 JSON
   - 快速迭代

### FreeSurfer 提供什么？

- ✅ 脑区的 3D 坐标
- ✅ 脑区标签和名称
- ✅ 网络归属（Visual, Motor, etc.）
- ✅ 大脑表面的几何形状
- ❌ **不提供**：时间序列活动数据

### 数据提供什么？

- ✅ 每个脑区在每个时间点的活动值
- ✅ 时间序列（如 200 个时间点）
- ✅ 特征值（可能是多维的）
- 📍 通过脑区 ID 映射到 FreeSurfer 定义的结构

## 💡 常见误解

### ❌ 错误理解 1
"必须同时有 FreeSurfer 文件和数据才能使用"

**正确**：FreeSurfer 创建结构，数据独立加载

### ❌ 错误理解 2
"FreeSurfer 包含时间序列信息"

**正确**：FreeSurfer 只有空间信息，时间序列来自数据

### ❌ 错误理解 3
"每次可视化都要重新生成 OBJ"

**正确**：OBJ 只生成一次，之后只更新 JSON 数据
