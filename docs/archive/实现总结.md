## FreeSurfer 表面数据支持

### 实现时间
2026-02-04

### 概述
实现了完整的 FreeSurfer 表面文件支持，允许用户在 Unity 可视化工作流中直接使用真实的大脑表面数据。

### 核心功能

**FreeSurferLoader 类** (`unity_integration/freesurfer_loader.py`):
- 加载 FreeSurfer 表面文件（.pial）
- 加载 FreeSurfer 注释文件（.annot）
- 提取脑区质心位置
- 转换为 TwinBrain atlas 格式
- 导出表面网格为 OBJ 格式

### 使用示例

```python
from unity_integration import run_unity_workflow, WorkflowConfig

config = WorkflowConfig(
    data_source='freesurfer',
    freesurfer_lh_surface='lh.pial',
    freesurfer_rh_surface='rh.pial',
    freesurfer_lh_annot='lh.Schaefer2018_200Parcels_7Networks_order.annot',
    freesurfer_rh_annot='rh.Schaefer2018_200Parcels_7Networks_order.annot',
    export_surface_mesh=True
)

results = run_unity_workflow(config)
```

### 数据流说明

**重要概念**：
- **FreeSurfer 文件**：提供静态的大脑解剖结构（脑区位置、网络归属）
- **时序数据**：需要从其他来源获取：
  - 真实 fMRI/EEG 数据
  - 训练模型的输出
  - 缓存的图结构数据

**正确的数据流**：
```
FreeSurfer 文件 (空间结构)
    +
fMRI/EEG 数据 (时序活动)
    ↓
JSON 导出 (完整的时空数据)
    ↓
Unity 可视化
```

**错误的做法**：
- ❌ FreeSurfer → 随机数据 → JSON
- ❌ 认为 FreeSurfer 包含时序信息

**正确的做法**：
- ✅ FreeSurfer（定义脑区）+ 真实fMRI（时序活动）→ JSON
- ✅ FreeSurfer（定义脑区）+ 模型输出（预测活动）→ JSON

### 如何加载真实数据

在 `workflow_manager.py` 的 `_load_freesurfer_data()` 方法中，当前使用占位符数据：

```python
# 当前（占位符）：
fmri_data = torch.randn(n_regions, n_timepoints, n_features)

# 应该改为加载真实数据：
from your_data_loader import load_fmri_data
fmri_data = load_fmri_data(subject_id, n_regions, n_timepoints)
```

或使用模型输出：

```python
# 使用训练好的模型生成预测
predictions = model.predict(initial_state, n_steps=n_timepoints)
fmri_data = predictions['fmri']
```

## Unity 集成系统

### 实现时间
2026-02-02

### 概述
实现了完整的 Unity 可视化集成系统，支持一键导出脑数据到 Unity 格式。

### 核心功能

1. **自动化工作流** (`WorkflowManager`)
   - 数据处理
   - 多格式导出（JSON, OBJ）
   - Unity 配置自动生成

2. **实时通信** (`BrainVisualizationServer`)
   - WebSocket 服务器
   - 虚拟刺激模拟
   - 前后端交互

3. **3D 模型生成** (`BrainOBJGenerator`)
   - 球体表示脑区
   - 连接线可视化
   - 时间序列动画

### 使用示例

```python
from unity_integration import run_unity_workflow, WorkflowConfig

config = WorkflowConfig(
    output_dir='output/unity',
    export_formats=['json', 'obj'],
    time_step=5
)

results = run_unity_workflow(config)
```

## 动态变异性权重

### 实现时间
2026-01

### 概述
基于EEG-fMRI数据变异性的动态加权训练策略，提高多模态数据融合效果。

### 核心思想
- EEG时间分辨率高但空间分辨率低
- fMRI空间分辨率高但时间分辨率低
- 根据数据变异性动态调整损失权重

### 使用方法

配置文件启用：
```yaml
training:
  use_dynamic_weighting: true
  dynamic_weighting:
    mode: "variability"  # 或 "snr"
    alpha: 0.7
```

代码启用：
```python
trainer = HeteroGCNTrainer(
    model=model,
    use_dynamic_weighting=True,
    dynamic_weight_config={
        'mode': 'variability',
        'alpha': 0.7
    }
)
```
