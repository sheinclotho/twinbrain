## ⚠️ 重要概念

### FreeSurfer 数据流

**必读**：如果您使用 FreeSurfer 文件，请务必理解：

1. **FreeSurfer 文件** = 只有空间结构（脑区位置、标签）
2. **时序数据** = 需要从 fMRI/模型/缓存获取
3. **正确流程** = FreeSurfer（空间）+ 时序数据 → JSON → Unity

详见：**[FreeSurfer使用指南.md](FreeSurfer使用指南.md)** 的"重要概念"部分
